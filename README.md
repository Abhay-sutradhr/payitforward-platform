## 🧭 **Introduction**

**Pay It Forward** is a web app designed to create a **healthy, non-profit community** where people can **help each other using their unique skills** — purely out of goodwill.  

No money or financial exchange is involved.  
Instead, users earn and spend **credit points** by completing or posting small tasks — building a **trust-based, self-sustaining community**.  

> 💬 *“A place where kindness fuels collaboration — and collaboration builds community.”*

---

## 💡 **The Concept**

This idea emerged from observing freelancing platforms, where even simple tasks often cost more than necessary.  
**Pay It Forward** offers a **zero-cost alternative** — where skills and time are traded for **credits**, not cash.

### 🧩 How It Works
1. Every new user receives **10 starting credit points**.
2. Credits can be used to **post jobs or requests** — e.g., fixing a bug or designing a small banner.
3. Other users can **apply to help**. Once selected, both parties can **chat inside the app** *(coming soon)* to finalize details.
4. After completion, the requester **rates the helper’s performance** — which influences eligibility for future tasks.
5. Ratings and credit points maintain a **healthy, trustworthy ecosystem**.

## 🧩 **Project Setup**

### ⚙️ Prerequisites
- ☕ Java JDK 11+
- 🐬 MySQL Server
- 📫 Postman (for API testing)

### 🧱 Setup Instructions

```bash
# Clone repository
git clone https://github.com/Abhaysutradhr/pay-it-forward.git
cd pay-it-forward

# Backend setup
cd backend
mvn spring-boot:run

# Frontend setup
cd ../frontend
npm install
npm run dev
